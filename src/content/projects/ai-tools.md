## What's in it

- **Chat agent.** A Node.js service on Cloud Run that answers website chat in the contact-center platform with
  GPT, and hands existing clients to a human.
- **Knowledge base.** A retrieval (RAG) index over Debt.com and Consolidated Credit content, built with
  Chroma and Vertex AI, so answers come from the brands' own articles.
- **Article summarizer** that drafts summaries for editors to review.
- **Image studio.** A small tool that generates illustrations with Gemini inside a designer-defined style,
  used to replace stock and copyrighted images across the sites.
- **Agentic engineering.** A harness of skills and rules that lets coding agents run, test and QA a production platform, with a human approving every release.
